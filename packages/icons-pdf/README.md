## Installation

```sh
npm install @tabler/icons-pdf
```

```sh
yarn add @tabler/icons-pdf
```

```sh
pnpm add @tabler/icons-pdf
```

You can also [download the latest release from GitHub](https://github.com/tabler/tabler-icons/releases).

## Package contents

All PDF files are stored in the `icons` directory, split by style:

| Path | Description |
| --- | --- |
| `icons/outline/*.pdf` | Outline icons |
| `icons/filled/*.pdf` | Filled icons |

## CDN

Every file is also available from jsDelivr. Replace `latest` with a specific version number to pin a release.

```
https://cdn.jsdelivr.net/npm/@tabler/icons-pdf@latest/icons/outline/home.pdf
```
